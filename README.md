# Проект Домашняя работа

## Описание:

Создаем банковское приложение для клиентского сервиса.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Anna-eliza/home_work
```

2. Установите зависимости:
```
pip install -r requirements.txt
```


## Использование:

1. Перейдите на страницу в вашем веб-браузере.
2. Создайте новую учетную запись или войдите существующей.
3. Создайте новую запись в блоге или оставьте комментарий к существующей.

##  Тесты

```bash
# установить зависимости
pip install pytest pytest-cov

# запустить тесты
pytest

# запустить с покрытием (HTML-отчёт в htmlcov/)
pytest --cov=src --cov-report=html
```
 ## Модуль `generators`

Модуль `src/generators.py` содержит вспомогательные инструменты для работы
с транзакциями: фильтрацию по валюте, ленивый перебор описаний и генерацию
номеров банковских карт.

Все функции модуля возвращают **ленивые итераторы** (генераторы), что
позволяет обрабатывать большие объёмы данных без лишнего расхода памяти.


Тесты лежат в `tests/`, фикстуры — в `tests/conftest.py`.
Покрытие: `src/masks.py`, `src/processing.py`, `src/widget.py`, `src/generators.py`
