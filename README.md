# Проект Домашняя работа

## Описание

Создаем банковское приложение для клиентского сервиса.

## Установка

1. Клонируйте репозиторий:

   ```
   git clone https://github.com/Anna-eliza/home_work
   ```

2. Установите зависимости:

   ```
   pip install -r requirements.txt
   ```


## Модули

### `src/masks.py`

Маскирование номеров банковских карт и счетов.

### `src/widget.py`

Маскирование данных в строке и форматирование даты.

### `src/processing.py`

Фильтрация и сортировка списка банковских транзакций.

### `src/generators.py`

Генераторы для работы с транзакциями: фильтрация по валюте, перебор
описаний и генерация номеров карт. Все функции возвращают ленивые
итераторы.

### `src/utils.py`

Загрузка списка транзакций из JSON-файла. При отсутствии файла,
пустом или некорректном содержимом возвращает пустой список `[]`.

### `src/services.py`

- `process_bank_search(data, search)` — поиск транзакций по подстроке
в описании (модуль `re`, регистронезависимо).
- `process_bank_operations(data, categories)` — подсчёт количества
операций по категориям (модуль `collections.Counter`, регистронезависимо).

### `src/external_api.py`

Конвертация суммы транзакции в рубли. Для `USD` и `EUR` используется
внешний сервис [Exchange Rates Data API](https://apilayer.com/marketplace/exchangerates_data-api).

**Настройка:** создайте `.env` на основе `.env.example` и укажите ключ:

```dotenv
EXCHANGERATES_API_KEY=ваш_ключ_здесь

src/decorators.py
Декоратор log логирует вызов функции: имя, результат при успехе;
имя, тип ошибки и аргументы при исключении. Если filename не задан —
пишет в консоль, иначе — в файл (режим дозаписи, utf-8).

src/main.py
Точка входа приложения. Реализует интерактивное меню:

Выбор источника данных: JSON, CSV или XLSX.

Ввод статуса фильтрации: EXECUTED, CANCELED, PENDING
(регистр ввода не важен).

Опциональная сортировка по дате (по возрастанию/убыванию).

Опциональный фильтр только по рублёвым транзакциям.

Опциональный поиск по слову в описании.

Вывод итоговой выборки с маскированием счетов и карт.

При пустой выборке выводится сообщение об отсутствии подходящих
транзакций.
