# Проект Домашняя работа

## Описание

Создаем банковское приложение для клиентского сервиса.

## Установка

1. Клонируйте репозиторий:

   ```
   git clone https://github.com/Anna-eliza/home_work
   ```

2. Установите зависимости:

   ```
   pip install -r requirements.txt
   ```

## Использование

Проект представляет собой набор модулей для обработки банковских транзакций:
маскирование карт и счетов, фильтрация и сортировка операций, генерация
описаний, логирование вызовов, загрузка данных из JSON и конвертация валют.

Примеры использования каждого модуля смотрите в соответствующих разделах ниже.

## Модуль `masks`

Модуль `src/masks.py` содержит функции для маскирования конфиденциальных
данных банковских карт и счетов.

### Структура

- `src/masks.py` — функции маскирования
- `tests/test_masks.py` — тесты

## Модуль `widget`

Модуль `src/widget.py` содержит функции для работы с виджетом: маскирование
данных в строке и форматирование даты.

### Структура

- `src/widget.py` — функции для виджета
- `tests/test_widget.py` — тесты

## Модуль `processing`

Модуль `src/processing.py` содержит функции для фильтрации и сортировки
списка банковских транзакций.

### Структура

- `src/processing.py` — функции фильтрации и сортировки
- `tests/test_processing.py` — тесты

## Модуль `generators`

Модуль `src/generators.py` содержит вспомогательные инструменты для работы
с транзакциями: фильтрацию по валюте, ленивый перебор описаний и генерацию
номеров банковских карт.

Все функции модуля возвращают **ленивые итераторы** (генераторы), что
позволяет обрабатывать большие объёмы данных без лишнего расхода памяти.

### Структура

- `src/generators.py` — функции-генераторы
- `tests/test_generators.py` — тесты

## Модуль `utils`

Модуль `src/utils.py` содержит функцию загрузки списка транзакций из JSON-файла.

### Поведение

Функция возвращает **список словарей** с данными о финансовых транзакциях.
Если файл:

- не найден,
- пустой,
- содержит невалидный JSON,
- содержит не список (например, словарь или число),

— функция возвращает **пустой список** `[]`.

### Структура

- `src/utils.py` — функция загрузки
- `data/operations.json` — файл с данными
- `tests/test_utils.py` — тесты

## Конвертация валют

Модуль `src/external_api.py` умеет конвертировать сумму транзакции в рубли.
Для транзакций в `USD` и `EUR` используется внешний сервис
[Exchange Rates Data API](https://apilayer.com/marketplace/exchangerates_data-api).

### Настройка

1. Зарегистрируйтесь на [apilayer.com](https://apilayer.com/) и получите API-ключ.
2. Создайте файл `.env` в корне проекта на основе шаблона `.env.example`:

   ```bash
   cp .env.example .env
   ```

3. Вставьте свой ключ в `.env`:

   ```dotenv
   EXCHANGERATES_API_KEY=ваш_ключ_здесь
   ```

   ⚠️ Файл `.env` добавлен в `.gitignore` и **не попадает** в репозиторий.

### Тесты

Тесты используют `unittest.mock` (`patch`), чтобы не делать реальных
запросов к API:

```bash
pytest tests/test_external_api.py
```

### Структура

- `src/external_api.py` — функция конвертации
- `.env.example` — шаблон переменных окружения
- `tests/test_external_api.py` — тесты с моками

## Декоратор `log`

### Что делает

Декоратор `log` логирует вызов функции: её начало, конец, результат при успешном
выполнении и информацию об ошибке при исключении.

### Параметры

- `filename` (необязательный) — путь к файлу, куда пишутся логи.
  - Если задан — логи идут в указанный файл (режим дозаписи, `encoding="utf-8"`).
  - Если не задан — логи выводятся в консоль через `print`.

### Что попадает в лог

**При успешном выполнении:**

- имя функции;
- результат выполнения.

**При ошибке:**

- имя функции;
- тип возникшей ошибки (`type(e).__name__`);
- входные параметры (`args` и `kwargs`).

Исключение не проглатывается, а пробрасывается наружу через `raise`.

### Структура

- `src/decorators.py` — декоратор
- `tests/test_decorators.py` — тесты
